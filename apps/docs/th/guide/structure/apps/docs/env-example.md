# .env[.example]

| ตัวแปร           | ค่า                      | คอมเมนต์                                                                                                                                            |
| --------------- | ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `PORT`          | `5173`                  | พอร์ตของ VitePress dev server อ่านผ่าน `dotenv` ใน `.vitepress/config.ts` — VitePress เองไม่โหลด `.env` ให้ ไม่ได้ใช้ใน Docker                          |
| `DASHBOARD_URL` | `http://localhost:3200` | ปุ่ม «ดูตัวอย่างเดโม» บนหน้าแรกจะพาไปที่ไหน ค่าถูก build ฝังเข้าไป — เอกสารเป็น static ไม่มี runtime config ใน Docker เป็น `/` (โดเมนเดียวกันหลัง proxy) |

## ความเชื่อมโยงกับไฟล์อื่น

- **`DASHBOARD_URL`** ต้องตรงกับ address ของ frontend คือ `PORT` ใน `apps/frontend/.env` ถ้าไม่ตรงจะไม่เห็นผลทันที: เอกสาร build และเปิดได้ปกติ แต่ปุ่ม «ดูตัวอย่างเดโม» จะพาไปยังพอร์ตที่ไม่มีอยู่
- **`PORT`** — `NUXT_PUBLIC_DOCS_URL` ใน `apps/frontend/.env` ชี้มาที่ค่านี้: เมนู «เอกสาร» และลิงก์ใน DevPanel ใช้ค่านี้

เปลี่ยนพอร์ตแล้วตรวจทั้งสองฝั่ง [ความเชื่อมโยงทั้งหมด](../../../env-variables#ตัวแปรที่เชื่อมโยงกัน)

วิธีสร้าง `.env` ที่ใช้งานจริง — [ตัวแปรสภาพแวดล้อม](../../../env-variables#ไฟล์)
