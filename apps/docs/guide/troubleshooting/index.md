# Частые проблемы

Симптомы и решения для ошибок, на которые чаще всего натыкаются при запуске проекта.

- [Не та версия pnpm](./pnpm) — `ERR_PNPM_UNSUPPORTED_ENGINE`, `pnpm --version` не совпадает с `packageManager`
- [Порт занят](./ports) — диалог о занятом порте, `address already in use`
- [Не создана Docker-сеть](./docker-network) — `docker network create` падает, `declared as external, but could not be found`
- [Нет файлов `.env`](./env-files) — `no port specified`, `env file ... not found`, не хватает новых переменных
