# package.json

Манифест документации. Скрипты вызываются через фильтр (`pnpm --filter @repo/docs dev`) или транзитивно из корневых команд.

| Скрипт    | Команда             | Что делает                              |
| --------- | ------------------- | --------------------------------------- |
| `dev`     | `vitepress dev`     | Локальный dev-сервер документации       |
| `build`   | `vitepress build`   | Статическая сборка в `.vitepress/dist/` |
| `preview` | `vitepress preview` | Локальный запуск собранной документации |
| `type-check` | `vue-tsc --noEmit`  | Проверка типов конфига и Vue-компонентов темы |

Фильтр здесь — полное имя пакета `@repo/docs`, а не `docs`, как у остальных приложений.

## Зависимости

Все пакеты — `devDependencies`: в образ попадает только собранная статика.

| Пакет | Зачем |
| --- | --- |
| `vitepress`, `vue` | Генератор документации и Vue для компонентов темы |
| `dotenv` | Чтение `apps/docs/.env` в `.vitepress/config.ts` |
| `vue-tsc` | Проверка типов конфига и компонентов темы |
| `@types/node` | Типы Node.js для конфига |

Что где лежит — [apps/docs](./).
