# .env[.example]

| Переменная      | Значение                | Комментарий                                                                                                                                                          |
| --------------- | ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `PORT`          | `5173`                  | Порт VitePress dev-сервера. Читается через `dotenv` в `.vitepress/config.ts` — сам VitePress `.env` не грузит. В Docker не используется                              |
| `DASHBOARD_URL` | `http://localhost:3200` | Куда ведёт кнопка «Посмотреть демо» на стартовой странице. Вшивается в сборку — доки статические, рантайм-конфига у них нет. В Docker — `/` (тот же домен за прокси) |

## Связи с другими файлами

- **`DASHBOARD_URL`** должен совпадать с адресом фронтенда, то есть с `PORT` в `apps/frontend/.env`. Расхождение заметно не сразу: доки соберутся и откроются, но кнопка «Посмотреть демо» приведёт на несуществующий порт.
- **`PORT`** — на него смотрит `NUXT_PUBLIC_DOCS_URL` в `apps/frontend/.env`: оттуда ведут пункт меню «Документация» и ссылка в DevPanel.

Меняете порт — проверьте обе стороны. [Все связки](../../../env-variables#связанные-переменные).

Как создать рабочий `.env` — [Переменные окружения](../../../env-variables#фаилы).
