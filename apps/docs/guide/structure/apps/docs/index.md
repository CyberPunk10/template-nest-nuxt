# apps/docs

VitePress. Страницы — обычные markdown-файлы, путь до файла становится URL.

```
apps/docs/
├── .vitepress/
│   ├── config.ts               конфиг: локали, sidebar, тема
│   ├── theme/                  кастомизация темы, компоненты витрины
│   └── locales/                переводы интерфейса (не страниц)
├── guide/                      страницы на русском
├── en/guide/                   те же страницы на английском
├── th/guide/                   и на тайском
├── index.md                    стартовая страница
└── Dockerfile                  сборка статики для образа nginx
```

## Три локали

Русский — основной, лежит в корне (`/guide/...`). Английский и тайский — в подпапках с тем же деревом файлов (`/en/guide/...`).

Структура страниц во всех локалях **одинакова**: добавили файл в `guide/` — добавьте его же в `en/guide/` и `th/guide/`, иначе ссылки в sidebar разойдутся. Сам sidebar задаётся в `config.ts` отдельно для каждой локали.

## Свой Dockerfile без запуска

Образ `apps/docs` ничего не поднимает: он только собирает статику, которую забирает образ nginx. Отдельного контейнера с документацией в Compose нет — подробнее в [apps/docs](./docker-image) раздела Docker.

Скрипты приложения — [package.json](./package-json).
