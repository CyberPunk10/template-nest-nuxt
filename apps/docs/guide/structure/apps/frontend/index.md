# apps/frontend

Nuxt 4. В отличие от backend, здесь расположение файлов **определяет поведение**: Nuxt сканирует папки и сам создаёт роуты, регистрирует компоненты и автоимпорты.

```
apps/frontend/
├── app/                        исходники приложения
│   ├── assets/css/             стили, которые обрабатывает Vite
│   ├── components/             Vue-компоненты (автоимпорт)
│   ├── composables/            композаблы (автоимпорт)
│   ├── layouts/                обёртки страниц
│   ├── pages/                  файловый роутинг
│   ├── plugins/                код при инициализации приложения
│   ├── utils/                  вспомогательные функции (автоимпорт)
│   └── app.vue                 корневой компонент
├── server/                     серверная часть (Nitro)
│   └── api/
│       ├── backend/            BFF-прокси в NestJS
│       └── health.get.ts
├── i18n/                       настройка @nuxtjs/i18n
├── public/                     отдаётся как есть: favicon, robots.txt
└── nuxt.config.ts
```

## Что даёт расположение файлов

| Папка | Соглашение |
| --- | --- |
| `pages/` | Имя файла становится маршрутом: `pages/tasks.vue` → `/tasks` |
| `components/` | Компоненты доступны в шаблонах без импорта. Вложенность входит в имя: `components/App/Sidebar.vue` → `<AppSidebar>` |
| `composables/`, `utils/` | Экспорты доступны везде без импорта |
| `plugins/` | Выполняются при старте. Числовой префикс задаёт порядок (`01.api.ts`), суффикс `.client` — только в браузере |
| `layouts/` | `default.vue` применяется ко всем страницам, если не указано иное |
| `public/` | Файлы отдаются с корня: `public/robots.txt` → `/robots.txt`, без обработки сборщиком |

## app/ и server/ — разные среды

`app/` — то, что попадает в браузер (и рендерится на сервере при SSR). `server/` — код, который выполняется **только** на сервере и в бандл клиента не входит.

Через `server/api/backend/` проходят все запросы к API: браузер обращается к своему же origin, Nuxt форвардит их в NestJS. Поэтому у бэкенда нет CORS-проблем в dev и его не нужно публиковать наружу в Docker — разбор в [Reverse proxy](../../../reverse-proxy).

Скрипты приложения — [package.json](./package-json).
