# .env[.example]

| Переменная        | Значение (dev)          | Комментарий                                                                                                                                                                                               |
| ----------------- | ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `NODE_ENV`        | `development`           | Режим приложения. Текущий `docker-compose.yml` переопределяет его на `production` — образы собираются в прод-конфигурации                                                                                           |
| `APP_ENV`         | `development`           | Прикладной режим (`development`/`production`/`prod_qa`/`test`). В Docker — `production`                                                                                                                   |
| `SWAGGER_ENABLED` | не задан                | Показывать ли Swagger UI на `/api/docs`. Если не задан — включён везде, кроме `production`. Задаётся отдельно от `NODE_ENV`, чтобы можно было открыть Swagger в проде для диагностики или скрыть локально |
| `PORT`            | `3100`                  | Порт backend при `pnpm dev`. В Docker переопределяется `BACKEND_INTERNAL_PORT` из корневого `.env`                                                                                                        |
| `CORS_ORIGIN`     | `http://localhost:3200` | Origin фронтенда, с которого разрешены запросы. В Docker переопределяется на `http://localhost` — [подробнее](../../../env-variables#cors-origin)                                                           |

## Авторизация

| Переменная                   | Значение (dev)      | Комментарий                                                                                            |
| ---------------------------- | ------------------- | -------------------------------------------------------------------------------------------------------- |
| `JWT_SECRET`                 | заглушка            | Обязательна, минимум 32 символа. Подпись access-токена — **сменить перед продом**                        |
| `JWT_EXPIRES_IN`             | `15m`               | Время жизни access-токена, формат `<число><s\|m\|h\|d>`                                                 |
| `REFRESH_TOKEN_SECRET`       | заглушка            | Обязательна, минимум 32 символа. Отдельный секрет от `JWT_SECRET` — **сменить перед продом**             |
| `REFRESH_TOKEN_EXPIRES_DAYS` | `7`                 | Время жизни refresh-токена в днях                                                                        |
| `BCRYPT_ROUNDS`              | `12`                | Стоимость хеширования пароля, 4–20. В проде ≥ 12; снижать до 4 имеет смысл только в тестах, ради скорости |

## Прочее

| Переменная       | Значение (dev)      | Комментарий                                                                                    |
| ---------------- | ------------------- | ------------------------------------------------------------------------------------------------ |
| `THROTTLE_TTL`   | `60000`             | Окно rate limiting в миллисекундах, на каждый IP                                                 |
| `THROTTLE_LIMIT` | `100`               | Максимум запросов за окно                                                                        |
| `ADMIN_EMAIL`    | `admin@example.com` | Админ создаётся при старте приложения. Если не задать — создание пропускается                     |
| `ADMIN_PASSWORD` | `password`          | Пароль этого админа. Хешируется через `BCRYPT_ROUNDS`, повторный старт существующего не трогает   |

## Связи с другими файлами

Часть переменных связана с соседними приложениями:

- **`CORS_ORIGIN`** должен совпадать с адресом фронтенда, то есть с `PORT` в `apps/frontend/.env`. Не совпал — браузер заблокирует запросы к API, при этом сервер ответит `200` и в логах всё будет чисто.
- **`PORT`** — на него смотрит `NUXT_BACKEND_URL` в `apps/frontend/.env`: по этому адресу Nuxt ходит в API при серверном рендеринге.

Меняете порт — проверьте обе стороны. [Все связки](../../../env-variables#связанные-переменные).
