# packages/shared

Общие типы и переводы. Единственный пакет, который используют **оба** приложения.

```
packages/shared/
├── src/
│   ├── i18n/           переводы: ru, en, th
│   └── index.ts        типы (DTO) и точка экспорта
├── package.json
└── tsconfig.json       extends base, добавляет resolveJsonModule
```

## Почему без сборки

Пакет отдаётся исходниками: `main` и `types` в `package.json` указывают прямо на `src/index.ts`, скрипта `build` нет. Компилируют его сами потребители — backend вместе со своим кодом через `tsc`, frontend через Vite.

Отдельный шаг сборки был бы лишним: `tsc` у бэкенда и Vite у фронтенда всё равно проходят по этим файлам, а `dist/` пришлось бы держать в актуальном состоянии и не забывать пересобирать.

## Что здесь держать

Всё, что должно совпадать на клиенте и сервере: формы запросов и ответов, перечисления статусов, тексты интерфейса. Если тип нужен только одной стороне — ему место в самом приложении, а не здесь.

Манифест пакета — [package.json](./package-json).
