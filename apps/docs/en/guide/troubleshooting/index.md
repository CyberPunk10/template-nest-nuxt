# Common problems

Symptoms and fixes for the errors most often hit when starting the project.

- [Wrong pnpm version](./pnpm) — `ERR_PNPM_UNSUPPORTED_ENGINE`, `pnpm --version` doesn't match `packageManager`
- [Port in use](./ports) — the busy port dialog, `address already in use`
- [Docker network not created](./docker-network) — `docker network create` fails, `declared as external, but could not be found`
- [Missing `.env` files](./env-files) — `no port specified`, `env file ... not found`, new variables missing
